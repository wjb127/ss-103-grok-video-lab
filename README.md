# ss-103 그록 영상 랩

랜딩 배경용 영상만 만드는 사이드. Grok Imagine으로 뽑고, 여기 쌓는다.

설치 없음. 브라우저 영상 파일만.

```
open index.html
```

라이브는 Vercel. 목록의 각 링크가 히어로 문구 + 배경 영상 한 조합.

## 루프

1. `briefs/`에 메모. 문구, 길이, 비율, 금지(텍스트·로고·사람 얼굴).
2. 뽑은 영상은 `pieces/<이름>/bg.mp4`.
3. `pieces/frame/`을 복사해 문구를 바꾸고, `video`에 `data-src="bg.mp4"`를 넣는다.
4. 루트 `index.html` 목록에 링크 한 줄 추가.

## 기본

- 배경용이라 글자, 로고, UI, 사람 얼굴은 넣지 않는다.
- 비율은 랜딩 히어로 기준 16:9. 모바일 풀블리드는 9:16을 따로.
- 루프되게 시작·끝이 비슷한 장면.
- 움직임은 느린 카메라나 환경만. 컷 전환 금지.
